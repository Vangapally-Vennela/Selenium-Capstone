# Selenium WebDriver with Java - Capstone Project

## Project Overview

This project is a Selenium WebDriver Automation Framework built using Java, Maven, TestNG, and Page Object Model (POM).

The framework automates the SauceDemo application:

https://www.saucedemo.com

The framework follows automation testing best practices including:

- Page Object Model (POM)
- Explicit Waits
- Configuration Management
- Reusable Utilities
- Data-Driven Design
- Screenshot Capture on Failure
- Extent Reporting
- Retry Mechanism
- Parallel Execution
- Headless Browser Execution
- Meaningful Assertions
